Aplicaciones que uso

No pretende ser una lista exhaustiva. Son herramientas que forman parte de mi estación y que puedo tomar como punto de partida para futuras notas.

QLog · Libro de guardia

registro

QLog

Mi aplicación de registro. Es sencilla, funciona en Linux y Windows y utiliza una base de datos SQLite.

Lo uso para registrar y consultar los contactos de la estación.

JTDX

digital

JTDX

Una variante de WSJT-X orientada al trabajo con señales débiles y modos digitales.

Lo uso para operar principalmente FT8 y FT4.

GridTracker

mapa

GridTracker

Reúne decodificaciones, contactos, reportes y otra información en una interfaz visual.

Lo uso para seguir la actividad y ubicar contactos sobre el mapa.

QSSTV

Programa para recibir y transmitir imágenes mediante televisión de barrido lento.

Lo uso para recibir actividades SSTV terrestres y de satélites.

Gpredict

Permite seguir satélites en tiempo real, consultar órbitas y anticipar próximos pases.

QSLet · v0.9.0

en desarrollo

Linux · Windows · Software libre

QSLet

Diseña, genera y envía tus propias QSL electrónicas.

QSLet importa contactos ADIF y permite crear tarjetas individualmente o por lotes. Incluye editor visual, perfiles de estación, plantillas de correo, vista previa y una bandeja de salida persistente.

  • Python
  • PyQt6
  • ADIF
  • GPL v3
